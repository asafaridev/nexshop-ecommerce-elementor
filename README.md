# 👟 NexShop - Premium Dark E-Commerce Platform

NexShop is an iconic, high-end WooCommerce landing page and product experience platform designed for limited-edition sneakers. Built using a **Dark Theme** aesthetic with premium gold accents (`#E1B13C`).

## ✨ Key Architectural Features
- **Cinematic Product Page:** Broken traditional WooCommerce layouts to create an immersive Nike/Digikala-inspired product single page.
- **Glassmorphism Header:** A sticky, transparent header with a fully dynamic "Login/Register" state and dynamic Ajax Menu Cart.
- **Optimized for Conversions:** Integrated psychological triggers (Social Proof/Customer Reviews) and high-contrast CTA buttons.
- **100% Mobile Responsive:** Custom breakpoints for flawless shopping experiences on mobile and tablet devices.

## 🛠️ Tech Stack & Tools
- **Environment:** LocalWP (Localhost Development)
- **CMS:** WordPress & WooCommerce
- **Page Builder:** Elementor Pro (Custom Containers & Flexbox Layouts)
- **Design Philosophy:** Luxury Dark UI / Visual Hierarchy

## 📦 How to Restore/Install this Project
If you want to deploy this project locally or on a live server:
1. Download the `nexshop-wordpress-project.zip` file from this repository.
2. Import the zip file directly into **LocalWP** or use the **All-in-One WP Migration** plugin to restore the database and files (`wp-content`).
3. Database credentials and configurations are pre-optimized.
